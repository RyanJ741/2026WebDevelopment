HTML is the standard code used to build websites. It acts like a skeleton, using simple tags to organize text, images, and links on a page. Without it, web browsers wouldn't know how to display a website's content.

CSS

CSS, which stands for Cascading Style Sheets, is the standard stylesheet language used to define the visual presentation and layout of web pages. While HTML structures the raw content of a website, CSS is responsible for controlling the design, including colors, fonts, spacing, and responsive positioning across different screen sizes. By separating a website's presentation from its underlying structure, it allows developers to apply a uniform aesthetic across an entire site using a single, centralized file

JavaScript

JavaScript is a high-level, versatile programming language that brings life and interactivity to the World Wide Web. While HTML builds the page structure and CSS provides the visual styling, JavaScript adds dynamic behavior, allowing web pages to respond to user actions without reloading. It powers modern web features such as interactive maps, animated graphics, drop-down menus, and real-time content updates.

AFrame

A-Frame is an open-source, entity-component web framework designed for building virtual reality (VR) and augmented reality (AR) experiences directly inside a web browser [1]. Developed originally by Mozilla [1], it allows developers to create 3D scenes using simple, declarative HTML tags without needing to write complex WebGL code [1].
